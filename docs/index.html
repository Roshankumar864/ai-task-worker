Autonomous AI Task Worker

Watch an AI worker take a plain-language request, operate a vendor portal and an internal ERP, recover from failures, stop for your approval, and get its result checked by an independent auditor agent.

What you are watching: recorded runs of the real harness against SimWorld, a simulated company. The retries, policy gate, approvals, credential vault, evidence capture and verifier are the actual code. The decisions in these recordings come from the scripted offline planner, a test double for the LLM used so the demo runs without an API key. Run it live with the LLM from the repo: python -m worker console.
